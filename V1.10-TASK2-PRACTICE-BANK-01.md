# V1.10 Task 2 Practice Bank — Batch 01

## Purpose

Broaden **full-length IELTS Academic Writing Task 2 transfer practice** without duplicating W01–W05 teaching or changing the Core 30 denominator.

V1.9 established that the remaining Writing gap is prompt breadth, not another diagnostic test or another Task 2 lesson.

## Scope

Add 10 original IELTS-style full-length prompts:

| Family | Prompt 1 | Prompt 2 |
| --- | --- | --- |
| Opinion / agree-disagree | WT2-OP-01 | WT2-OP-02 |
| Discussion + own opinion | WT2-DISC-01 | WT2-DISC-02 |
| Advantages / disadvantages | WT2-ADV-01 | WT2-ADV-02 |
| Problems / solutions | WT2-PS-01 | WT2-PS-02 |
| Two-part questions | WT2-TWO-01 | WT2-TWO-02 |

All prompts are original practice material. They are not official IELTS questions.

## Learner workflow

`Choose prompt → Plan → Write 250+ words → Self-check → Save first evidence → Copy AI coaching prompt → Return 2–3 priorities → Revise → Save retry evidence`

Practice Mode exposes the task checklist and AI coaching workflow.

40-minute Test Mode hides the task checklist and disables AI coaching during the timed attempt.

## Data reuse

No parallel Task 2 learner-data storage is introduced.

- drafts → existing `ielts-self-learning-v1.writingDrafts`;
- plans → existing `ielts-self-learning-v1.notes`;
- first/retry attempts → existing `ielts-adaptive-v1.productiveEvidence.writing`;
- returned priorities → existing `ielts-adaptive-v1.aiFeedbackReturns.writing`;
- retry comparison → existing feedback-return comparison structure;
- Writing productive priority continues to route teaching ownership to W05.

Bank evidence uses `lessonId = WT2-BANK` and the prompt id as `blockId`/`promptId`, so independent prompts remain distinguishable without adding a storage schema.

## Evidence guardrails

- 250+ words required before Task 2 bank evidence can be saved.
- Evidence is process/learning evidence, not an official IELTS band.
- External AI scores are not imported.
- At least two actionable returned feedback priorities are required before logging a feedback cycle.
- A feedback cycle closes only after a saved `Revision / retry` event.
- V1.9 Diagnostic Center may naturally count a valid Task 2 `first` attempt as Writing baseline evidence because it already consumes productive evidence.

## Runtime

- `writing-task2-bank-v110.js`
- injected on the IELTS page;
- uses shared `render-lifecycle-v15.js` enhancement lifecycle;
- no document-wide MutationObserver;
- no permanent polling;
- one `setInterval` exists only while the explicit 40-minute timer is running.

## QA gates

### Static

`tests/validate-writing-task2-v110.mjs`

Verifies:

- exactly 10 prompt ids;
- exactly 2 prompts per family;
- original-source provenance;
- 250-word evidence threshold;
- productive/AI-feedback schema reuse;
- no new Task 2 storage key;
- shared render lifecycle;
- no fake precise band prompt.

### Chrome

`tests/browser-writing-task2-v110.html` + `.sh`

Verifies:

1. 10 prompts / 5 families × 2;
2. 249 words cannot save evidence;
3. 260 words can save first evidence;
4. draft persists in existing core `writingDrafts`;
5. returned feedback priorities save to existing adaptive schema;
6. retry is preselected when feedback is pending;
7. 275-word retry closes feedback and records positive self-check delta;
8. prompt switching works;
9. Test Mode hides checklist and disables AI coaching;
10. Task 2 first evidence is visible to V1.9 Diagnostic Center as Writing baseline evidence.
