## 3. Listening `word-limit` — 3 / 3 reviewed

Questions:

- `QL02-Q3` — true answer-form / word-limit discipline: complete `main ____` with `library entrance` under a two-word limit;
- `QL05-Q2` — identify a mentioned item that is explicitly unnecessary (`printed booking email`);
- `QL05-C3` — retrieve the notebook's maximum length (`12 pages`) under a short-answer instruction.

### Semantic judgement

The historical tag is broader than the actual three question processes:

- `QL02-Q3` is a genuine response-length / duplication-control item;
- `QL05-Q2` behaves more like a mentioned-but-not-required distractor;
- `QL05-C3` asks for a numeric content constraint (maximum pages), not a failure to count answer words.

The three signals therefore do **not** establish a coherent repeated transfer weakness. More importantly, all three are already inside QL02/QL05 local practice, where the learner can inspect feedback and retry.

### Decision

`listening-word-limit → TAUGHT-UNROUTED → QL02/QL05`

No LR Repair and no reuse route. This review intentionally does not destructively retag existing Lab questions because there is no current Test/Mock routing need, no false recurring GAP, and changing the tags would unnecessarily perturb established LR01 / routing audit counts. Future new questions should use more precise tags when the distinction matters.

## Why no runtime routing was added

Existing-practice routing exists to convert **non-retriable Test/Mock errors** into a useful Core → Lab practice path. It is not a mechanism for making every Core/Lab error point to another lesson.

For these five families:

- 0 / 15 signals come from Mini Tests;
- 0 / 15 signals come from Full Mock;
- all 15 signals are already in the instructional activity that teaches the relevant skill;
- direct Practice-mode feedback / Retry is therefore stronger than a reuse CTA;
- frequency alone provides no evidence for a new Repair lesson.
