# V1.3 Learner-Journey E2E QA

Date: 2026-08-26
Baseline: `main` after Quick Placement + L01–L05 production-audio closure.

## Goal

Verify one real learning loop:

`Placement → Study Plan / Today → lesson → Lab / Mini Test → Error Notebook → Repair → Retry → review → Full Mock → backup / restore`

## Automated coverage

- Placement and prerequisite-safe adaptive routing.
- Weak Mini Test evidence rebalances Study Plan priorities.
- Wrong standard-lesson questions can be unlocked and retried.
- Saved lesson errors stay in Error Notebook during retry and close automatically only after a checked correct answer.
- Mini Test / Full Mock errors do not expose an invalid `#/lesson/<test-id>` single-question retry route.
- Repair guided-practice items can be retried after a wrong check.
- Repair completion is blocked until every guided-practice item is checked and correct.
- Placement + L01–L05 production-first audio and labelled browser-voice fallback remain covered.
- Full Mock structure, Error Notebook handoff and history are covered.
- Placement, Study Plan, Error Notebook, Repair evidence, Mini Test history, Full Mock history, productive evidence and AI feedback survive backup/restore.
- Restored state remains healthy in Diagnostics.
- GitHub Actions browser smoke covers core desktop routes plus mobile IELTS / Full Mock shell.

## Defect found and fixed

### E2E-01 — Practice/Repair retry loop was not executable

Before this audit, a checked wrong standard lesson answer became permanently disabled even though Practice Mode and Error Notebook told the learner to retry. Repair lesson questions behaved the same way, and a Repair lesson could be marked complete without completing guided practice.

Fix:
- add `Retry` to wrong Practice Mode lesson questions;
- add `Retry question` from Error Notebook for standard lesson/Lab sources;
- close a saved lesson error automatically only after a successful checked retry;
- keep Mini Test / Full Mock errors on test-level retry workflows;
- add Repair-question retry;
- require all Repair guided-practice answers to be checked and correct before completion.

Regression: `tests/validate-repair-retry-loop.mjs` plus expanded `tests/qa-learner-journey.mjs`.
