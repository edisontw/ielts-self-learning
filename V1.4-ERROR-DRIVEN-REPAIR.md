# V1.4 Error-Driven Vocabulary / Grammar Repair

Date: 2026-08-26
Baseline: V1.3 production E2E closure at `3dd68b176b129f42ff4de107f157cefae3dd4422`.

## Goal

Expand Vocabulary / Grammar Repair only where the current question bank provides repeated Error Notebook evidence. Do not create generic grammar lessons merely to increase lesson count, and do not convert IELTS skill errors into language-system Repair when the underlying problem is test strategy or information processing.

## Repeatable error-tag inventory

`tests/audit-error-tags.mjs` scans the current core lessons, Question Type Labs, Mini Tests, and Full Mock data. Questions are de-duplicated by question ID before tag frequency is calculated.

Current audit:

- 388 unique tagged questions
- 99 exact error tags
- 84 semantic families

Largest semantic families include:

- `detail`: 37
- `paraphrase`: 32
- `number`: 27
- `main-idea`: 26
- `answer-type`: 14
- `distractor`: 14
- `scope`: 13
- `correction`: 11
- `inference`: 11

High frequency alone is not a Repair criterion. `detail`, `number`, `main-idea`, `distractor`, `scope`, and `correction` primarily represent IELTS task execution or comprehension processes and remain in the relevant Reading / Listening lesson and Lab pathways.

## Routing defect found

The original Repair recommendation logic compares Error Notebook tags and Repair `triggerTags` using exact string equality. VG01 contained a generic `paraphrase` trigger, while most real paraphrase errors are tagged `reading-paraphrase`, `listening-paraphrase`, or related prefixed forms. As a result, the largest real paraphrase signal could fail to trigger an appropriate Repair, while a bare Full Mock `paraphrase` tag could incorrectly favour the collocation-focused VG01 lesson.

V1.4 therefore separates paraphrase from collocation Repair and registers the real exact tag variants used by the current bank.

## First evidence-backed Repair extensions

### VG04 — Paraphrase: Same Meaning, Different Form

Evidence: 32 audited questions in the paraphrase semantic family across core lessons, Labs, Mini Tests, and Full Mock.

Focus:

- lexical paraphrase;
- grammatical reformulation;
- perspective shift;
- preserving claim direction and scope;
- rejecting keyword traps that change meaning.

VG01 remains the collocation Repair lesson and no longer captures generic `paraphrase` errors.

### VG05 — Use Grammar to Predict the Answer Type

Evidence: 14 audited `answer-type` questions, with explicit grammar-prediction use in Reading Sentence / Summary Completion and Listening Form / Notes / Sentence Completion.

Focus:

- predict noun / adjective / phrase / time-type requirements from surrounding grammar;
- use articles, possessives, prepositions, singular/plural form, and sentence position as filters;
- verify meaning and word limit after grammatical prediction.

This is a genuine transferable grammar Repair rather than a new IELTS question-type lesson.

## Curriculum boundary

VG04 and VG05 are V1.4 Repair extensions. They do **not** change the completed first 30-unit core curriculum or its `/30` Progress denominator. The original core Repair units VG01–VG03 remain part of that 30-unit scope.

The extensions use the same standard lesson URL contract:

- `#/lesson/VG04`
- `#/lesson/VG05`

They reuse the existing Repair learner-state contract:

`wrong → Retry → correct all guided items → Finish → saved Repair evidence`
