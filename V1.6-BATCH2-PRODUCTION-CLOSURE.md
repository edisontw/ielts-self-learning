# V1.6 Batch 2 Production Closure

Date: 2026-08-27

## Scope

V1.6 Batch 2 adds one evidence-driven Reading Skill Repair unit after a coverage-overlap audit:

- `RR02` — **Infer Only What the Evidence Supports**

The audit deliberately rejected five higher-frequency families as new Repair lessons because existing Core / Question Type Lab instruction already teaches those decisions:

- Reading detail → R02 / R05 / QR02 / QR03
- Listening detail → L02 / L03 / L05 / QL05
- Listening distractor → L04 / QL01
- Listening correction → L04 / QL06
- Reading scope → R04 / QR01 / QR03

Reading inference was the only current candidate with repeated test evidence but no direct Core/Lab instructional owner.
