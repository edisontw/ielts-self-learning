## 1. Listening final-decision — 3 / 3 reviewed

| Question | Actual decision |
| --- | --- |
| `ML01-Q10` | If Wednesday is full, use the Tuesday repeat session rather than booking both or switching to Monday |
| `ML02-Q10` | After discussing payment options and weather contingencies, the participant finally decides to book online that evening |
| `ML03-Q10` | The participant’s final statement combines two decisions: pay the member fee online and bring fruit |

### Semantic judgement

These questions are homogeneous. They require the learner to keep earlier possibilities provisional and identify the **completed action or decision at the end of the relevant exchange**.

This is not an untreated skill:

- **L04** teaches `possible option → correction / contrast → FINAL meaning`, including abandoned plans, preference changes, conditional options and delayed commitment.
- **QL01** explicitly trains option states as `possible / rejected / final` under one-play Listening Multiple Choice conditions.

### Decision

Add existing-practice routing:

`listening-final-decision → L04 → QL01`

No LR Repair is added.

## 2. Listening main-idea — 3 / 3 reviewed

The Full Mock signals are not identical surface questions, but all require global meaning rather than an isolated detail:

| Question | Actual decision |
| --- | --- |
| `MA01-L21` | Identify the group’s revised research focus after rejecting the broader initial question |
| `MA01-L34` | Identify the main reason simple tree counts are inadequate: cooling performance varies |
| `MA01-L40` | Identify the lecturer’s final overall conclusion: urban trees should be treated as long-term infrastructure |

### Semantic judgement

The coverage matrix previously marked this family as a gap only because Full Mock uses the bare tag `main-idea`, while **L01** uses more specific error tags. The underlying skill is nevertheless already explicit in L01:

- lesson objective: follow the **overall meaning** without stopping at individual words;
- first task: identify the speakers’ **main problem**;
- teaching: track conversation structure and final direction rather than isolated vocabulary.

There is no equally exact Question Type Lab devoted to Listening gist/main idea. Routing a Full Mock main-idea error to an unrelated MCQ or matching Lab would manufacture a transfer pair that the curriculum does not actually support.

### Decision

Classify semantically as:

`Listening main-idea → TAUGHT-UNROUTED → L01`

This classification is encoded only in the coverage audit via a semantic teaching override. It creates no runtime CTA, storage, or Repair lesson.

No LR Repair is added.

## 3. Listening scope — 3 / 3 reviewed

| Question | Actual decision |
| --- | --- |
| `ML02-Q8` | Under the specific condition “on Saturday morning”, identify the payment method that is **not** accepted: cash |
| `ML03-Q9` | Answer exactly what is **included in the fee**: tea, coffee, and a light snack; not lunch |
| `ML04-Q6` | Identify exactly **who** receives a provided sandwich: students who selected a meal when registering |

### Semantic judgement

These are not broad claim-scope questions like Reading TFNG. They are Listening retrieval errors caused by losing a controlling restriction: time, inclusion/exclusion, or participant group.

Existing instruction is adequate:

- **L05** teaches predicting the answer category from the question before audio arrives.
- **QL05** explicitly trains exact requested detail, including `Who / Where / When / How many / Why`, and instructs learners to underline the question word and any time reference.

### Decision

Add existing-practice routing:

`listening-scope → L05 → QL05`

No LR Repair is added.

## 4. Listening sequence — 3 / 3 reviewed

| Question | Actual decision | Semantic subtype |
| --- | --- | --- |
| `ML02-Q4` | After passing the library, turn right immediately after the pharmacy | spatial route order |
| `ML03-Q4` | After turning left at reception, locate Studio Five as the second door on the right after the kitchen | spatial route order |
| `ML04-Q3` | After the morning break, Group A and Group B exchange sampling locations | procedural / temporal event order |

### Semantic judgement

The common tag hides two different processes.

The first two questions are close to **QL03 Map & Plan Labelling**, which teaches continuous location tracking and directional updates. The third question is not map navigation; it asks what event occurs next in a project schedule.

A single LR Repair would therefore teach an artificial “sequence” abstraction that is broader than the evidence. A generic Core → Lab route is also unsafe: previous review already established that L01/L05 are prerequisites for QL03 but do not themselves teach map direction with equal precision.

### Decision

Keep:

`listening-sequence → GAP-REVIEW`

No existing-practice route and no LR Repair are added. Future evidence should first distinguish spatial-route sequence from procedural/event sequence with more precise tags or question metadata.

## 5. Reading reference — 3 / 3 reviewed

| Question | Actual decision |
| --- | --- |
| `MR02-Q9` | Resolve “it” in “who can actually reach it” → **shade** |
| `MR03-Q8` | Resolve “These concerns” → residents’ objections/worries about intentional flooding, mosquitoes and access |
| `MR04-Q8` | Resolve “These measures” → reduced fees, neighbourhood collection points and housing partnerships |

### Semantic judgement

This family is highly coherent across three independent Reading Mini Tests:

- one simple pronoun (`it`);
- one demonstrative phrase referring to an earlier set of concerns;
- one plural demonstrative referring to an earlier list of interventions.

All require the same underlying process: identify plausible antecedents, check grammatical/number compatibility, substitute the candidate, and verify semantic/logical coherence.

The current Reading Core/Lab curriculum teaches main idea, structure, paraphrase, evidence, TFNG, headings, MCQ, completion and information location, but it does **not** directly teach anaphoric reference resolution as an owned skill/error target.

### Decision — add RR03

New Skill Repair:

**RR03 — Resolve What Reference Words Point To**

Trigger:

- `reading-reference`
- Reading skill only
- requires observed error evidence

Instructional rule:

`look back for candidates → match number/meaning → substitute into sentence → verify logic`

The guided practice uses three new contexts rather than copying the Mini Test items:

1. `this problem` referring to an earlier event;
2. `These measures` referring to a two-action list;
3. `it` referring to a rejected proposal rather than a nearby physical noun.

RR03 reuses the existing Skill Repair runtime and the all-correct mastery gate.
