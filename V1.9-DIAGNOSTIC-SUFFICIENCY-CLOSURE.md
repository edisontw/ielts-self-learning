## Question

After the Diagnostic Evidence Center reaches Placement + 4/4 skill coverage, does the site still need a separate large Full Diagnostic before targeted content expansion?

## Decision

**No separate new four-skill diagnostic test bank is justified now.**

The current system already has enough independent evidence routes to establish and progressively strengthen a learning profile:

- Quick Placement for the short starting profile;
- MR01–MR04 + MA01/MA02 Reading for timed Reading evidence;
- ML01–ML04 + MA01/MA02 Listening for timed Listening evidence;
- productive Writing first/retry evidence plus Mock Writing;
- productive Speaking first/retry evidence from the existing Speaking Practice Bank.

The product should continue to call this **diagnostic evidence**, not an exam-equivalent Full Diagnostic or one precise IELTS band.

## Reading — sufficient; do not add forms

Reading already has:

- four independent timed Mini Tests;
- two independent Full Mock Reading sections;
- existing error-tag / Repair / routed-practice infrastructure.

The Diagnostic Center requires one timed form for baseline and two distinct forms for broader evidence. This is enough for the current product stage.

**Decision:** no new Reading diagnostic form, MR05, or additional Reading test solely for diagnosis.

## Listening — sufficient; do not add forms

Listening already has:

- four independent timed Mini Tests;
- two independent Full Mock Listening sections;
- production audio on earlier surfaces, with MA02 browser-voice status explicitly labelled;
- existing error-tag / Repair / routed-practice infrastructure.

**Decision:** no new Listening diagnostic form or ML05 solely for diagnosis. MA02 production audio remains a separate media-quality upgrade, not a diagnostic-content requirement.

## Writing — baseline exists; breadth gap remains in Task 2 practice

Writing is not empty:

- W01–W05 already teach Task 2 skills;
- W01 includes an 80–120 word mini Task 2 writing block;
- W05 already provides one full **Opinion Essay** workspace with a 250–380 word target and the full attempt → self-check → AI feedback → revision loop;
- Full Mock Writing provides Task 1 + Task 2 under test conditions;
- Academic Writing Task 1 separately has a mature five-lesson course and 12 reusable prompts across planned visual families.

Therefore the gap is **not “no Task 2 workspace.”** The gap is that reusable full-length Task 2 practice is concentrated in one opinion-essay workspace rather than spread across the main Task 2 instruction families.

### Highest-value next content gap

Create a **Task 2 Practice Bank** that reuses W01–W05 teaching and the existing productive feedback/retry workflow.

Recommended minimum breadth:

1. Opinion / agree-disagree;
2. Discussion + own opinion;
3. Advantages / disadvantages or outweigh;
4. Problems / solutions;
5. Two-part / direct questions.

Start with **2 original full-length prompts per family = 10 prompts**.

This is transfer breadth, not ten new lessons. Do not expand the 30-unit core denominator.

## Speaking — prompt quantity is sufficient; standardization is secondary

The existing Speaking Practice Bank already contains:

- 12 Part 1 topics / 48 questions;
- 12 Part 2 cue cards;
- 12 linked Part 3 sets / 48 questions;
- 108 original prompts/questions total;
- transcript, timer/recorder, AI evidence and retry workflow support.

The current diagnostic baseline is intentionally simple: one substantial first-attempt transcript of 60+ words; broader evidence requires substantial first attempts from multiple prompt/block sources.

A more standardized one-sitting Parts 1–3 diagnostic sampler could improve comparability, but **lack of prompt volume is not the problem**.

**Decision:** do not add more Speaking question quantity now. A structured Parts 1–3 diagnostic sampler is secondary to the Task 2 breadth gap and can reuse the existing bank when/if implemented.

## Full Diagnostic concept — current interpretation

The V1.1 Full Diagnostic concept is now implemented as a **progressive evidence system**, not as one mandatory long exam:

`Quick Placement → timed R/L evidence → substantial W/S evidence → broader evidence through later independent forms`

This preserves the original idea that diagnosis can be split across sessions while avoiding unnecessary duplicate test content.

A dedicated long four-skill diagnostic should be reconsidered only if actual learner use shows that the current evidence system cannot make useful next-step decisions.

## V1.9 closure criteria

All are satisfied:

1. learner can see Placement + four-skill evidence coverage;
2. missing evidence produces one actionable next step;
3. existing valid evidence automatically satisfies steps;
4. Reading/Listening distinguish baseline vs multiple independent forms;
5. Writing/Speaking enforce substantial-attempt thresholds;
6. Speaking Mock beta completion alone does not create false Speaking evidence;
7. 4/4 returns the learner to Today rather than demanding more testing;
8. no fake overall IELTS band is created;
9. no new learner-data schema was needed;
10. the complete Diagnostic Evidence progression is verified on deployed GitHub Pages.
