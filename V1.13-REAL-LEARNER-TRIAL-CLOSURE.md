## Learner-friction fixes accepted during V1.13

### Skill identity and Chinese help

PR #82 fixed three concrete learner-facing problems found during production UAT:

- ambiguous `LB` identity on Learning Better cards;
- weak visual separation among Learning Better / Reading / Listening / Writing / Speaking in the Learn grid;
- 中文輔助 changed state but had no visible effect on Learn until an individual lesson was opened.

The smallest fix added explicit skill identity, low-saturation skill accents and visible Traditional Chinese summaries when Chinese help is enabled.

### Corrected-error review scheduling

A2 exposed a state-synchronization defect in the spaced-review path. A corrected retry could reach the due point and be treated as needing the initial correction seed again while no review attempt had yet been recorded.

PR #83 made the correction seed one-time by preserving the `corrected-in-retry` marker. Corrected items now enter the intended 3-day review schedule and can progress through later recall ratings instead of being repeatedly re-seeded.

### Study Plan review completion continuity

A5 exposed a continuity gap between real review evidence and the Study Plan. Completing a due review could remove the Today due-review priority while leaving the corresponding Study Plan review session uncompleted.

PR #87 added bounded review-evidence synchronization so a newly completed real review can auto-complete the current review session once, then Today advances to the next plan action and Progress agrees with Today.

### Test harness hardening

Several failures during A1/A2/A5 validation were test-harness defects rather than product defects, including stale deployed module caching and stale DOM references during enhancement rerenders. These were fixed in the harness without changing learner behavior merely to satisfy tests.

## Accepted limitations / deferred observations

### Representative human observation has not been performed in-repository

The deterministic seeded journeys prove route, state, recommendation, Test Mode and production-browser behavior. They cannot prove human trust, hesitation, terminology comprehension or whether a learner personally understands *why* a recommendation is useful.

The optional Phase D small real-user observation remains a valid future evidence source when representative IELTS learners are available. It is not an unresolved P0/P1 product defect and is not required to keep V1.13 open.

### README repository-hygiene note

The README still contains an older V1.6-era `Next implementation priorities` section. The current source-of-truth hierarchy places this closure document and `CHATGPT_PROJECT_CONTEXT.md` above that historical section, but the README should be synchronized as low-risk documentation hygiene before defining a new implementation milestone.

No other accepted P2/P3 learner-facing limitation was demonstrated by the final seeded production UAT.

## Closure decision

V1.13 is closed.

Do not reopen A1–A5 merely to repeat already-green seeded journeys. Future implementation should start only from new evidence: representative learner observation, a reproducible production defect, or a separately approved product milestone.
