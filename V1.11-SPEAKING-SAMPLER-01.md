# V1.11 Standardized Speaking Parts 1–3 Sampler — Batch 01

## Purpose

Improve comparability of Speaking evidence **without adding more speaking questions**.

The existing Speaking Practice Bank already contains 108 original prompts/questions. V1.11 reuses its 12 linked Part 1 → Part 2 → Part 3 sets and turns one linked set into a standardized five-response evidence sample.

## Sample structure

For one existing linked set:

- Part 1: first 2 questions from the linked familiar-topic set;
- Part 2: the linked cue card;
- Part 3: first 2 questions from the linked discussion set.

No new prompt bank is created.

## Evidence threshold

A linked sample can be saved only when all are true:

- Part 1 combined transcript: ≥50 words;
- Part 2 transcript: ≥100 words;
- Part 3 combined transcript: ≥100 words;
- total transcript: ≥300 words.

The thresholds are evidence-quality gates, not official IELTS timing or scoring rules.

## Learner flow

`Choose linked set → answer/record Parts 1–3 → paste/edit transcripts → self-check → save first sample → copy transcript-only AI coaching prompt → return 2–3 priorities → retry same linked sample → save retry evidence`

Pacing aids are available for practice:

- Part 1: 45 seconds;
- Part 2 preparation: 1 minute;
- Part 2 long turn: 2 minutes;
- Part 3: 90 seconds.

The Part 1 / Part 3 timers are practice pacing aids, not official per-question IELTS limits.

## Data reuse

No new learner-data storage key is introduced.

- responses reuse core `speakingTranscripts` using the existing bank prompt IDs;
- sampler evidence reuses `ielts-adaptive-v1.productiveEvidence.speaking`;
- returned priorities reuse `aiFeedbackReturns.speaking`;
- evidence owner remains `SPB01`;
- each linked set gets a distinct evidence `blockId` such as `SPS-SET-SKILL`;
- evidence records explicit `sampleParts: ['part1','part2','part3']` and per-part word counts.

This means previous bank transcripts can automatically appear in the sampler and sampler transcripts remain reusable in ordinary bank practice.

## Diagnostic integration

V1.9 Diagnostic Center already counts substantial first Speaking evidence.

- one valid standardized linked-set first attempt = Speaking baseline evidence;
- first attempts from two distinct linked sets naturally produce `Broader evidence` under the existing distinct-block rule.

No new diagnostic scoring rule is required.

## AI / pronunciation guardrail

The coaching prompt is transcript-only.

It must not score or judge:

- pronunciation;
- stress;
- intonation;
- pauses;
- hesitation;
- actual speech rate.

Those require audio evidence and learner playback. No fake precise or official Speaking band is imported.

## QA

### Static

`tests/validate-speaking-sampler-v111.mjs`

Checks:

- existing linked Speaking bank is reused;
- Parts 1–3 / 300-word thresholds remain explicit;
- existing productive / feedback-return schemas are reused;
- no sampler-specific storage key;
- shared render lifecycle;
- no permanent observer/polling;
- transcript-only pronunciation and fake-band guardrails.

### Browser

`tests/browser-speaking-sampler-v111.html` + `.sh`

Checks:

1. 12 linked sets available;
2. exactly five responses per sample;
3. 250 total words is insufficient;
4. Part 1 50 + Part 2 150 + Part 3 100 = 300 unlocks save;
5. saved first evidence records Parts 1–3 and per-part counts;
6. responses persist through existing `speakingTranscripts`;
7. returned feedback priorities use existing adaptive schema;
8. retry is preselected while feedback is pending;
9. a 320-word retry closes the feedback cycle and records self-check change;
10. a second linked-set first attempt upgrades V1.9 Diagnostic Center Speaking to `Broader evidence`.

## Out of scope

- new Speaking questions;
- pronunciation scoring from transcript;
- official/fake Speaking band score;
- speech recognition or automated transcription;
- new Core lessons;
- MA03 / MR05 / ML05;
- MA02 audio production.
